# Employee Performance Dashboard

## Purpose
Large monitor display in the technician workspace showing real-time performance metrics and friendly competition.

## Display Features

### Live Performance Board
- **Today's completions** per technician
- **This week's totals** with progress bars
- **Monthly leaderboard** showing top performers

### Recognition System
- **Daily champion** highlight (most repairs completed)
- **Quality star** for technicians with zero failed QC
- **Weekly winner** announcement with achievement badge

### Team Metrics
- **Total devices repaired today** (team goal tracking)
- **Average repair time** by technician level
- **Current queue status** (pending repairs by type)

## Business Value
- Motivate technicians through friendly competition
- Increase visibility of individual contributions
- Encourage quality work alongside speed
- Build team spirit and engagement

:::tip Display Setup
Designed for large monitor/TV in workshop area - auto-refreshing, no interaction needed.
:::
