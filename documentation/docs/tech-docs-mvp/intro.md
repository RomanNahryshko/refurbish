# Tech Docs - MVP

Welcome to the MVP documentation for ReMobile Refurbish ERP System.

## 📋 What's Included in MVP

This section covers all features and requirements approved for the initial MVP release:

### Core Modules
- **Batch Intake**: Managing incoming phone batches
- **Phone Tracking**: Tracking phones through the workflow
- **Repair Jobs**: Queue-based repair management
- **Inventory**: Spare parts tracking
- **Admin & Reporting**: KPIs and dashboards

### Key Features
- Dr. Phone integration
- Queue-based repair assignment
- Manual QC processes
- Basic invoice tracking

Navigate through the sidebar to explore each module in detail.
