# Login to the System

This page shows you how to get into the ReMobile system.

## When you need this
Your first day at work, or anytime you need to access the system.

## Steps to login

1. Open your web browser
2. Go to the ReMobile website (your manager will give you the link)
3. Enter your email address
4. Enter your password
5. Click "Sign In"

## First time login

If it's your first day:
1. Use the temporary password your manager gave you
2. The system will ask you to create a new password
3. Make it something you'll remember but others can't guess
4. Click "Update Password"

## What happens next
You'll see your homepage with the menu items you can use. Different jobs see different menus - that's normal!

## Common problems
- **Wrong password?** Ask your manager to reset it
- **Can't see the website?** Check if you're connected to company WiFi
- **Forgot your new password?** Tell your manager - they can help
