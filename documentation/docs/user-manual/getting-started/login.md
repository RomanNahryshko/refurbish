# Login to the System

This page shows you how to get into the ReMobile system.

## When you need this
Your first day at work, or anytime you need to access the system.

## Steps to login

1. Open your web browser
2. Go to the https://workflow.remobile.eu/
3. Enter your email address
4. Enter your password
5. Click "Sign In"

<img src="/user-manual-images/login.jpg" alt="Login Screenshot" width="320" />

## First time login

If it's your first day:
1. Use the temporary password your manager gave you
2. The system will ask you to create a new password
3. Make it something you'll remember but others can't guess
4. Click "Change Password":

<img src="/user-manual-images/change-password.jpg" alt="Change Password Screenshot" width="320" />

## What happens next
You'll see your homepage with the menu items you can use. Different user types see different menus - that's normal!

## Common problems
- **Wrong password?** / **Forgot your new password?** - ask your manager to reset it.
