# Welcome to ReMobile Refurbish

This system helps you track phones from the moment they arrive until they're ready to sell. You'll use it every day to manage phone repairs, check quality, and keep everything organized.

**What you need to know:** ReMobile tracks each phone with two numbers - the IMEI (15 digits) and our Internal ID (8 digits). Every phone goes through these steps: arrives → gets checked → gets repaired → gets checked again → gets graded A, B, or C.

**Your job matters:** Whether you're doing repairs, quality checks, or managing batches, this system keeps track of everything so we can deliver great refurbished phones to customers.
