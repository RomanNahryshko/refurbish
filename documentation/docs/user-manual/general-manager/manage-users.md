# Managing Users

This page shows you how to add, edit, and remove employees in the system.

## When you need this
- New employee starts work
- Someone changes roles or gets promoted
- Employee leaves the company
- Someone forgets their password

## Adding a new employee

1. Go to "Admin" in the main menu (only you can see this)
2. Click "Users" 
3. Click "Add New User"
4. Fill in their information:
   - **Full Name:** Their real name
   - **Email:** They'll use this to log in
   - **Role:** Pick their job (see roles below)
   - **Technician Level:** Only if they're a technician
   - **Employee ID:** Optional, for your records
5. Click "Create User"
6. Give them their temporary password (system will show you)
7. Tell them to change it on first login

## User roles explained

**Admin** - Can do everything you can do (be careful with this!)

**General Manager** - Same as you (for other managers)

**Operations Manager** - Handles batch intake and creates repair jobs

**QC Controller** - Does final quality control and grading

**Technician** - Fixes phones (must also pick L1, L2, or L3 level)

## Editing existing users

1. Find the user in the list
2. Click "Edit" next to their name
3. Change what you need to change
4. Click "Save Changes"

**Common changes:**
- Promote technician from L1 to L2 or L3
- Change someone from technician to operations manager
- Update their name or email address

## Removing users

1. Find the user in the list
2. Click "Deactivate" (don't delete - we need records)
3. Confirm you want to deactivate them

**Note:** Deactivated users can't log in but their work history stays in the system.

## Resetting passwords

1. Find the user in the list
2. Click "Reset Password"
3. Give them the new temporary password
4. Tell them to change it when they log in

## Best practices
- **Use real email addresses** - people need to log in
- **Start new technicians at L1** - let them prove themselves first
- **Don't delete users** - deactivate them instead
- **Keep employee IDs consistent** - helps with payroll and HR
