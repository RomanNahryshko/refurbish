# Dashboard Overview

https://workflow.remobile.eu/dashboard - the dashboard shows you the most important numbers about the business in one place.

## When you need this
Every morning to see how yesterday went, and anytime you want to check current performance.

## How to access the dashboard

1. Click "Dashboard" in the main menu (only managers see this)
2. The dashboard loads automatically with today's data
3. Use the date picker to see different time periods

<img src="/user-manual-images/dashboard1.jpg" alt="Dashboard overview" width="600" />

## Main sections you'll see

**Device Processing Numbers**
- Phones received today
- Phones in repair right now  
- Phones completed today
- Phones ready to ship

**Repair Performance**
- Housing changes completed
- Glass changes completed
- Battery changes completed
- Software updates completed
- Other repairs completed

**Quality Control Stats**
- Phones that passed final QC
- Phones that failed and went back to repair
- Grade distribution (how many A, B, C grades)

**Team Performance**
- Which technicians are working
- How many jobs each person completed
- Average time per repair type

## Using the date picker

Click the calendar icon to change what time period you're looking at:
- **Today** - see what's happening right now
- **Yesterday** - review how yesterday went
- **This week** - see weekly trends
- **This month** - look at bigger patterns
- **Custom range** - pick any date range you want

## What the numbers tell you

**High numbers are good:**
- Devices completed
- QC pass rates
- Technician productivity

**Watch out for:**
- Too many phones stuck in repair
- High QC failure rates
- Technicians with very low completion numbers

## Pro tips
- **Check every morning** - catch problems early
- **Compare to last week** - are we getting better or worse?
- **Look for patterns** - do we always struggle on Mondays?
- **Use it in meetings** - show the team how they're doing
