# Grading Standards

Assign grades to phones that pass QC.

## The three grades

**Grade A - Best Condition**
- Screen is perfect (no scratches, no marks)
- Housing looks like new (no dents, no scratches)
- All functions work perfectly
- Battery health is excellent
- Looks almost brand new

**Grade B - Good Condition**  
- Screen has very minor scratches (barely visible)
- Housing has light wear but no major damage
- All functions work properly
- Battery health is good
- Shows some use but still looks nice

**Grade C - Acceptable Condition**
- Screen has visible scratches but no cracks
- Housing has scratches, small dents, or wear marks
- All functions work (this is required!)
- Battery holds charge but may not be perfect
- Shows clear signs of use but still sellable

## Key rule

**When in doubt, go lower** - Better to under-promise than disappoint customers.

## Remember
- If anything doesn't work → Fail it (don't grade)
- Screen condition matters most  
- Small problems add up
- Always complete full QC checklist before grading
