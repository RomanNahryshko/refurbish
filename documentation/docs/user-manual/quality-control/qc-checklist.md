# Quality Control Checklist

Use this checklist for every phone you test. Don't skip any steps!

## Physical Inspection

**Screen:**
- [ ] No cracks anywhere
- [ ] No dead pixels (black spots)
- [ ] No bright spots or lines
- [ ] No deep scratches
- [ ] Screen protector removed (if present)

**Housing/Body:**
- [ ] No cracks in back cover
- [ ] No missing pieces
- [ ] No deep dents or gouges
- [ ] All ports are clean and undamaged
- [ ] Camera lenses are clean and uncracked

**Buttons and Ports:**
- [ ] Power button clicks properly
- [ ] Volume buttons work
- [ ] Home button works (if present)
- [ ] Charging port is clean and straight
- [ ] Headphone jack works (if present)
- [ ] SIM tray opens and closes properly

## Software Testing

**Basic Functions:**
- [ ] Phone turns on
- [ ] Touch screen responds everywhere
- [ ] Phone unlocks properly
- [ ] Settings menu opens
- [ ] Phone can be factory reset

**Connectivity:**
- [ ] WiFi connects to network
- [ ] Cellular signal works
- [ ] Bluetooth turns on
- [ ] GPS/location works

**Camera and Audio:**
- [ ] Front camera takes clear photos
- [ ] Back camera takes clear photos
- [ ] Camera focuses properly
- [ ] Speaker plays sound clearly
- [ ] Microphone records clearly
- [ ] Earpiece works for calls

**Battery and Charging:**
- [ ] Phone charges when plugged in
- [ ] Charging port holds cable firmly
- [ ] Battery percentage increases while charging
- [ ] Phone doesn't get too hot while charging
- [ ] Battery lasts reasonable time when unplugged

## Final Checks

- [ ] All repairs were completed properly
- [ ] No new damage from repair process
- [ ] Phone feels solid (no loose parts)
- [ ] All original problems are fixed

## If anything fails
Mark as "Fail", select needed repairs, and write clear notes. The system will automatically create repair jobs.

Note: If imported Battery Health is below 92%, Battery Change may already be pre-selected for you. You can remove it if not needed.
