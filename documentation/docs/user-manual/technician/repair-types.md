# Repair Types Guide

This page explains each type of repair and who can do them.

## Housing Change (L1 or L3 Technicians)

**What it is:** Replacing the back cover or frame of the phone

**Common problems:**
- Cracked back glass
- Dented metal frame  
- Missing pieces
- Scratched housing

**What you need:** New housing part, proper tools, steady hands

**Tips:** Take your time removing old adhesive. Clean everything before installing new housing.

## Glass Change (L2 or L3 Technicians)

**What it is:** Replacing the front screen or glass

**Common problems:**
- Cracked screen
- Dead pixels
- Touch not working
- Broken front glass

**What you need:** New screen assembly, heat gun, adhesive, precision tools

**Tips:** Be very careful with ribbon cables. Test touch function before final assembly.

## Battery Change (L3 Technicians Only)

**What it is:** Replacing the phone's battery

**Common problems:**
- Won't hold charge
- Phone dies quickly
- Battery swollen
- Won't charge at all

**What you need:** New battery, adhesive strips, proper tools

**Tips:** Always discharge old battery first. Don't puncture batteries - they can catch fire!

## Software Update (L3 Technicians Only)

**What it is:** Updating the phone's operating system

**When needed:**
- After battery replacement (about 80% of the time)
- When phone has software bugs
- To improve performance

**What you need:** Computer, USB cable, update software

**Tips:** Make sure phone has enough charge before starting. Don't disconnect during update!

## Other Repairs (L3 Technicians Only)

**What it includes:**
- Camera replacement
- Speaker repair
- Charging port fix
- Button replacement
- Any other hardware problem

**What you need:** Specific parts for each problem, various tools

**Tips:** Always describe exactly what you're fixing in the job notes. These repairs can be tricky!

## Who Can Do What?

- **L1 Technicians**: Housing changes only
- **L2 Technicians**: Glass changes only
- **L3 Technicians**: All repairs (housing, glass, battery, software, other)

## Remember
- **Stay in your lane** - L1 and L2 only do repairs you're qualified for
- **L3 versatility** - L3 technicians can handle any repair type
- **Ask for help** - if you're not sure, ask an experienced technician
- **Quality matters** - take time to do it right the first time
- **Test everything** - make sure your repair actually fixed the problem
