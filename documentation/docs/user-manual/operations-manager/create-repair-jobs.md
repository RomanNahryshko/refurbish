# Creating Repair Jobs

This page shows you how to assign repair work to technicians.

## When you need this
After you've done initial QC and found phones that need repairs.

## Steps to create repair jobs

1. Go to "Repair Jobs" in the main menu
2. Click "Create New Repair Job"
3. Fill in the details:
   - **Device:** Search by IMEI or Internal ID
   - **Repair Type:** Choose what needs fixing:
     - Housing Change (L1 technicians only)
     - Glass Change (L2 technicians only) 
     - Battery Change (L3 technicians only)
     - Software Update (any technician)
     - Other (explain in description)
4. Add notes about the problem
5. Click "Create Job"

## Repair types explained

**Housing Change** - Cracked or damaged back cover. Only L1 technicians can do this.

**Glass Change** - Broken screen or front glass. Only L2 technicians can do this.

**Battery Change** - Dead or weak battery. Only L3 technicians can do this.

**Software Update** - Usually needed after battery changes. Any technician can do this.

**Other** - Anything else like camera, speaker, charging port problems. L3 technicians handle these.

## What happens next
- The repair job appears in the technician queue
- Technicians pick jobs they're qualified for
- You can track progress in the Repair Jobs page

## Tips for success
- **Be specific in notes** - "Screen cracked in top-left corner" is better than "broken screen"
- **One job per problem** - don't combine housing + battery in one job
- **Check technician levels** - make sure the right people can do the work
- **Software updates** - create these separately, don't assume technicians will remember
